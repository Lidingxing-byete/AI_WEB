芯诊 AI · Phase 2.5 串口验证页

基准工程专用：Web Serial API 直读串口，并自动判别乱码与丢行。 全部处理在浏览器本地完成，数据不上传任何服务器。

连接

点击后由浏览器弹出设备选择列表（这是浏览器的安全要求，必须由点击触发）。 默认参数即基准工程所用：115200 / 8 / 无校验 / 1 停止位 / 无流控。

接收

字节 0
行数 0
非 ASCII 占比 0%
tick 计数 —
丢行 0
尚未开始接收

说明

自动判别逻辑：解析基准工程输出中的 tick N， 若相邻 N 不连续则计为丢行；非 ASCII 字符占比偏高提示乱码（波特率/时钟问题）。

浏览器要求：Chrome 或 Edge。Firefox 不支持 Web Serial API。

独占访问：串口被本页打开期间，其他串口工具无法同时访问，请先关闭它们。
