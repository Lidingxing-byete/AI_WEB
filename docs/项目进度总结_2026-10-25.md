### 4.2 评测结论（9 用例：6 正 + 3 负）

- **Top-1 命中 6/6**，负例误报 0/3，证据可追溯 8/8，自动幻觉筛查 0 条可疑。
- **消融结论（必须如实讲）**：
  - 去掉 RAG → 命中率不变，但参考条目 45 → **0**。RAG 的贡献是**可追溯性**，不是准确率。
  - 去掉症状加权 → 0/9 用例排序改变。**当前测试集上影响为 0**（每例仅 1–2 个候选）。
  - 关键词朴素基线在 3 个负例中误报 2 个，复现 N-01/N-03 两个坑。
- **纯 LLM 基线（qwen2.5:7b，3 次采样）**：
  - 正例 **6/6 与规则层打平**（模型 2301ms vs 规则层 <10ms）。
  - 负例：规则层误报 0，纯 LLM 误报 1（按实质口径 2）。
  - ⚠️ **不得宣称"比大模型更准"**。真实差异在：可追溯、材料不足不硬猜、超范围不套结论、能承载真正的 `[实测-硬件]`。
- **禁止口径**：不得用 9 个样本宣称准确率 100% 或任何准确率数字。

### 4.3 本轮抓出并修复的真实缺陷（不隐瞒）

| # | 缺陷 | 处理 |
|---|---|---|
| 1 | 空材料仍给出确定根因（把"没看到"当"有错"） | 新增 `has_usart_evidence()` 前置判定，无 USART 证据时 21 条规则一律 `unknown` |
| 2 | I2C 代码被硬套 UART 结论 | 同上 + 编排层超范围 followup |
| 3 | 材料不足缺引导 | 列出需补充的材料清单 |
| 4 | 幻觉筛查器自身误报（注释宏名、`NVIC_Init` 子串匹配、期望值误判） | 剥离注释、词边界、期望语境识别 |
| 5 | **重诊断抹掉用户回填的实测记录** | 快照 + 回放 + 状态回补 + 已排除沉底 |
| 6 | `(tid)` 非元组导致 sqlite 异常 → 出现"假通过" | 改 `(tid,)`，补状态码断言 |
| 7 | 守卫漏检「已验证…无误」、静默丢弃越权步骤 | 收紧正则；改为整段作废并写明原因 |
| 8 | C2 样例 `#define HSE_VALUE` 写在 include 之后被库默认值挡住 → 上板不乱码 | 移到 include 之前并加 `#ifndef` |
| 9 | 纯 LLM 基线初版漏传编译日志（对模型不公平） | 补齐输入 |
| 10 | SSE 60s < 7B 模型冷启动 | 改为 `max(60, LLM_TIMEOUT_S + 60)` |
