## 四、本次核对结果：自撰语料**无技术性错误**

以教程工程作为「已知正确」参照，核对 `docs/corpus/` 的自撰内容：

| 技术点 | 教程源码实际做法 | 我们的语料表述 | 结论 |
|---|---|---|---|
| USART1 总线 | `RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE)` | USART1 挂 APB2 / PCLK2 | ✅ 一致 |
| TX 引脚模式 | PA9 `GPIO_Mode_AF_PP`，`GPIO_Speed_50MHz` | 必须为复用推挽输出 | ✅ 一致 |
| RX 引脚模式 | PA10 `GPIO_Mode_IPU` | 「常用浮空输入或上拉输入」，R-S4-01 判据写 `IN_FLOATING 或 IPU` | ✅ 一致（未写成"必须浮空"，无错误） |
| 波特率 | 教程用 **9600** | 9600 与 115200 在 72MHz 下误差均为 0，均列为排查基准 | ✅ 一致 |
| printf 重定向 | 9-1 有 `fputc` 实现 | R-S5-01 搜索 `fputc / _write / __io_putchar` | ✅ 一致 |
| 接收中断 | 9-2 有 `USART_ITConfig(USART1, USART_IT_RXNE, ENABLE)` + `NVIC_Init` | R-S4-01 / R-S4-02 覆盖 | ✅ 一致 |

**结论**：`docs/corpus/` 的 23 条规则与 40 条卡片**无需修正**。

### 附：从教程源码提取的公有技术事实（可用于工程参考，不入库）

- 教程四个串口工程统一使用 **9600 波特率**，非 115200
- 9-1 为**纯发送**（仅初始化 PA9，未初始化 PA10），且已实现 `fputc` 重定向
- 9-2 / 9-3 / 9-4 均为 **TX+RX + RXNE 中断 + NVIC**，PA10 用 `GPIO_Mode_IPU`
- `printf` 在 Keil 下使用需勾选 **Use MicroLIB**（Options for Target → Target）—— 这是 C6 案例的实际坑点
- NVIC 使用 `NVIC_PriorityGroup_2`，USART1_IRQn 抢占 1 / 子优先级 1
