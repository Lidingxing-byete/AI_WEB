## 四、引用规范（编写语料时的硬性要求）

### ✅ 允许

| 类型 | 示例 |
|---|---|
| 公有技术事实（自撰表述） | 「USART1 挂载在 APB2 总线，使用前须使能其外设时钟」 |
| 寄存器名与位名 | `RCC_APB2ENR`、`USART_SR`、`GPIO_CRL` |
| 章节级引用 | 「依据 RM0008 Ch.19 USART」「依据 RM0008 Ch.7 RCC」 |
| 自撰的配置流程说明 | 用自己的话描述初始化顺序 |
| 自撰的示例代码 | 为说明概念而写的片段，标注「本项目自撰示例」 |

### ❌ 禁止

| 禁止项 | 说明 |
|---|---|
| 手册原文段落 | 即便改写为同义也不得逐段翻译复制 |
| 本地知识库原文 | D1 决策，即便原文标注「已审」 |
| 手册章节截图 | 版权风险 |
| 固件库源码片段 | 不入库、不引用 |
| 未标注来源的结论 | 每条规则/卡片必须有 `source_ref`；无来源者 UI 标 `[来源未确认]` |

### 引用写法模板

依据：RM0008 Ch.19 USART（STM32F1 系列参考手册）

## 五、适用性与防套用要求

`PROJECT_PLAN.md` 第六节明确要求：涉及寄存器、时钟、引脚复用和外设行为时，**必须确认资料适用范围**；不同芯片、库版本和工程配置之间**不得无依据地相互套用**。

落地措施：

| 措施 | 说明 |
|---|---|
| 每条语料带 `applicable_chip` | 检索时按芯片过滤，不匹配则降权或标注警告 |
| 每条语料带 `not_applicable_note` | 明确写出不适用的情形（如「F4 系列的 USART 时钟源规则不同，不适用本条」） |
| 库版本标注 | 区分 SPL V3.5 与 HAL，避免 API 混用 |
| MVP 范围声明 | 系统只承诺 STM32F103C8T6 + USART + SPL；超出范围时前端提示「超出当前支持范围」 |
